# Pinkaholic: fashion style direction from crumble.co

## Goal
Take the visual language of crumble.co (playful, warm, retro-homely D2C storefront) and translate it into a style direction for Pinkaholic, a pink-led fashion e-commerce site.

## Steps
1. Audit crumble.co: fonts, colours, layout patterns, signature motifs.
2. Write the direction: `design/pinkaholic/STYLE.md` (tokens, type, motifs, components, Crumble → Pinkaholic mapping).
3. Build a static homepage mockup: `design/pinkaholic/index.html` (self-contained, no external images).
4. Check desktop and phone widths in the browser.

## Assumptions
- Pinkaholic sells women's clothing and accessories; prices in AUD.
- Crumble's paid display face (Reckless) is swapped for a free Google Font with the same soft, high-contrast serif feel (Fraunces).
- Mockup only: no cart, checkout or CMS wiring.
