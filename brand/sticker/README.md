# Heart can sticker and rose logo

Imperial Script wordmark in a pink gradient, with a speckled stencil rose for the dot on the last i. Built by `../make_sticker.py`.

| File | Use |
|---|---|
| `sticker-heart-cream.svg` / `-blush` / `-wine` | Can sticker, 80 x 76 mm, vector (all text outlined) |
| `sticker-heart-*-cutline.svg` | The same, plus a blue dashed die-cut line on its own layer (`cutline`) for the printer |
| `sticker-heart-*.png` | 300 dpi, transparent background, for printers that want PNG (most auto-cut around the shape) |
| `logo-rose.svg` / `.png` | The wordmark with the rose dot, for the website and packaging |
| `rose.svg` / `.png` | The rose on its own: social profile picture, favicon, tissue paper, seals |

Notes for the printer:
- The white border around the heart is the die-cut margin (about 2 mm).
- The rose speckle is made of tiny dots. Ask for a proof if printing smaller than 50 mm.
- Colours are RGB. Ask the printer to match to the pink of the PNG proof.
